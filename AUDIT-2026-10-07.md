# Prism — Pricing-Claim & Architecture Audit (2026-10-07)

Auditor: orchestrated code audit + `npx e2e explore` against a local seeded instance
(`PORT=3123 DB_PATH=/tmp/prism-audit.db ADMIN_TOKEN=admin-test DEMO_TOKEN=demo-panel-2026 bun run src/server.ts`).

## Architecture

Bun + Hono single process, embedded SQLite (WAL), no build step:

```
landing/index.html ──► static (also mounted at /)
demo/index.html    ──► static demo storefront (persona simulator, data-prism-convert)
public/snippet.js  ──► 9.1 KB vanilla JS client (served as /snippet.js and immutable /snippet.v1.js)
src/server.ts      ──► Hono app: /api/identify, /api/decide, /api/events, /api/variants CRUD,
                       /api/stats (Wilson CIs + holdout), /api/export, /api/visitors DSR,
                       /privacy /security /terms, /admin dashboard
src/db.ts          ──► schema: visitors, variants, events + matchAudience()
src/bandit.ts      ──► Thompson sampling over Beta(conv+w, imp-conv+1)
src/dashboard.ts   ──► server-rendered admin SPA (string template)
```

Request path: browser → snippet → POST /api/decide → audience match (traits) → deterministic
holdout hash → bandit pick → DOM ops applied post-paint → events beaconed back. No model in the
request path (true as claimed). Fail-open on any error (true as claimed).

### Technical claims (landing / README / brief / trust pages)

| # | Claim | Verdict | Evidence |
|---|-------|---------|----------|
| T1 | 9 KB snippet, 3 KB gzipped, zero deps | ✅ TRUE | 9,100 B raw (8.9 KiB), 3,243 B gzipped (3.2 KB). Vanilla JS, no imports. |
| T2 | Decision cache 5 min → zero network latency on repeat views | ✅ TRUE | `snippet.js`: `Date.now() - cached.ts < 300000`; cached decisions applied synchronously before fetch. |
| T3 | First-party cookie, 400 days, SameSite=Lax | ✅ TRUE | `max-age=34560000;path=/;samesite=lax`. Matches /privacy text. |
| T4 | SPA-aware: re-decides on pushState/popstate | ✅ TRUE | history hooks + popstate listener in snippet. |
| T5 | Insert ops idempotent, survive framework re-render | ✅ TRUE | `data-prism-owned` tagging + `clearOwned()`; MutationObserver fingerprint re-apply. |
| T6 | Fail open on API failure | ✅ TRUE | `.catch(function(){})` on decide; every op try/caught. |
| T7 | Conversions require a prior impression | ⚠️ PARTIAL | Enforced for variant conversions (verified: orphan conversion dropped, `recorded:0`). **Not enforced for control (`variantId=null`) conversions** — poisoning hole. |
| T8 | SRI-pinnable immutable snippet, published hash | ❌ FALSE | `/snippet.v1.js` serves `max-age=1y, immutable` ✓, but the published hash `sha384-sEOeqZqZMm…` **does not match** the bytes. Actual: `sha384-g8aa4Fhxe/l9XqedTYl+17fbXzXZ5YoQFCE93vdQhe9CIXaPRoXBoBJEmRV1+rlB`. Any page using the published integrity attr **blocks the script entirely**. |
| T9 | "Hash printed at startup" (server comment) | ❌ FALSE | No startup code exists in `server.ts` (no listen, no console.log); `index.ts` is empty. |
| T10 | Demo token write-capable on demo site only | ✅ TRUE | Verified: POST site=demo → 201; site=evil → 401; toggle/delete of non-demo variant → 401. |
| T11 | DSR endpoints token-gated | ✅ TRUE | Verified: no token → 401; demo token → 200. README API table still says auth "—" (stale doc). |
| T12 | Klaviyo snippet: real Liquid fields, computed lastOrderDays | ❌ FALSE | Published one-liner renders `lastOrderDays = 20733.7` for a customer whose true value is ~17 days (verified with liquidjs). Liquid filter args can't be chained; needs `assign`. |
| T13 | Segment integration recipe | ✅ TRUE | `analytics.identify(userId, traits); prism.identify(traits)` — sound. |
| T14 | Thompson sampling bandit per segment | ✅ TRUE | `bandit.ts` gamma-ratio Beta sampler; audience-filtered candidates per selector; live distribution skews to winner (181/200 to seeded winner). |
| T15 | Holdout ~10% deterministic | ✅ TRUE | Hash is uniform (10.1% over 10k ids); same visitor → same arm across calls. |
| T16 | Dashboard: Edit button, humanized rules | ✅ TRUE | `editVariant()` prefills builder (saves-as-new by design); `humanize()` renders "cartItems ≥ 3". |
| T17 | "1M visitors/mo" scale | ➖ UNTESTED | SQLite WAL single-writer; no load test performed. |
